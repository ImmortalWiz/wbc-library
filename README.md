## 📜 The Three Iron Laws of the Codex

1. **Constitutional Immutability:** Once merged into `main`, files in `wbc-library` represent inviolable physical and political laws. No character, spell, or scene in any downstream repository may contradict an established WBC law without triggering a CI/CD continuity failure.
2. **Strict Physical Realism:** Magic in this universe is not whimsical or consequence-free. Spells dissipate according to celestial cycles; foci (wands) bottleneck thermodynamic energy; wandless casting taxes human musculature and nervous systems.
3. **Dualist Theological Conflict:** The world is caught between two fanatical systems:
   * **The Covenant of the Vessel (Muggle cult):** Magic is an invading cosmic parasite (*"The Seep"*) requiring harsh physical penance (*"Corrective Friction"*).
   * **The Sacred Lineage (Pureblood hegemony):** Magic is an inherited divine right granting dominion over common mortals.

## 🤖 Instructions for AI Context Engines

* **Querying Before Drafting:** When checking if a character can cast a spell or execute an action, cross-reference the relevant file in `02_cosmological_magic/` and `03_institutional_jurisprudence/`.
* **Citation Rule:** When providing rationale or running continuity audits, cite the exact file path (e.g., `[REPO 1: wbc-library/02_cosmological_magic/fundamental_theory/02_the_gaps_framework.md]`).
* **No Unsanctioned Magic:** Do not invent new branches of magic or wandless powers on the fly. If a concept is not codified in `wbc-library`, it does not exist.

## 👤 Guide for Human Contributors

1. **Proposing New World Laws:** To add a new law, create an issue or pull request with the RFC tag. Detail:
   * Biological, cosmological, or socio-economic costs.
   * How it interacts with Harry's psychological flaws.
   * Downstream impacts on existing entities in [`war-entities`](https://github.com/ImmortalWiz/war-entities).
2. **File Naming Convention:** All files must follow the numerical categorization scheme: `XX_category/YY_subcategory/ZZ_topic_name.md`.
